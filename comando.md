#Basicos				Funcion
1 add 					Añade el archivo en donde trabaje 
2 commit 				Saca la "Foto" de todo para guardarlo 
3 status 				Mustra todos los estados de los archivos

#Ramas			
1 checkout 				lo uso para crear o moverme entre ramas
2 switch 				lo uso para cambiar la rama 
3 git log --oneline --graph --all.	me da un grafico de todas las ramas con sus cambios/nodosX

#Guardado 
1 push origin 				se usa desp de un commit y sube la rama al hub
2 pull origin 				se usa al principio, es para traer lo que esta en el sv 
3 git push --all origin			Sube todas las ramas

#Conflicto
1 merge 				luego de ver en el archivo el final de cada rama, me permite solucionar el conflicto uniendo o sobreponiendo.
